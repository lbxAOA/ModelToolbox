# ModelIngest 重构方案总结

## 八、总结

本重构方案基于用户需求确认（2026-07-30），采用 PixelRAG 的独立包架构，核心改进：

### 8.1 架构演进

```
当前单体架构              →    独立包管道架构
├── 两阶段流水线           →    ├── render (视觉渲染) ⭐新增
├── 配置分散              →    ├── fetch (内容获取)
└── 解析器耦合            →    ├── parse (格式解析)
                              ├── clean (内容清洗)
                              ├── distill (知识蒸馏)
                              ├── organize (知识库组织)
                              └── 统一编排 + 灵活配置
```

### 8.2 核心创新

1. **视觉处理能力**：新增 render 阶段，使用 Playwright 渲染网页截图
2. **多模态解析**：visual_parser 处理图像，保留表格、图表等视觉信息
3. **双通道检索**：为后续文本+图像向量检索奠定基础
4. **独立包架构**：7个独立包，清晰解耦，易于扩展

### 8.3 实施路径

- **Day 1**：核心基础设施（包结构 + render + parse + 配置）
- **Day 2**：编排器集成（orchestrator + CLI + 测试）
- **后续**：视觉模型集成、性能优化、生态完善

### 8.4 关键决策记录

基于 2026-07-30 需求讨论：

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 架构风格 | ✅ 独立包架构 | 最大化解耦，支持单独发布 |
| 视觉处理 | ✅ 新增 render 阶段 | 解决传统爬虫 RAG 效果差的问题 |
| 向后兼容 | ✅ 破坏性更新 | 简化 CLI，降低复杂度 |
| 配置系统 | ✅ Python + YAML 混合 | 灵活且类型安全 |
| 新依赖 | ✅ 可以引入 | Playwright、Pillow 等 |
| 开发时间 | ✅ 1-2天快速启动 | 优先核心功能，后续迭代 |

### 8.5 预期效果
