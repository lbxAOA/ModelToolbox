# 个人自动化脚本

## 快速使用

```powershell
# 快速提交
.\scripts\quick-commit.ps1 "fix: bug description"

# 发布前检查
.\scripts\pre-release-check.ps1 -Version "0.3.0"

# 生成更新日志
.\scripts\generate-changelog.ps1

# 完整发布（测试+Git+NPM）
.\scripts\publish.ps1 -Version "0.3.0" -Message "feat: new features"

# 发布到 PyPI
.\scripts\publish-pypi.ps1

# 试运行
.\scripts\publish.ps1 -Version "0.3.0" -DryRun
```

## 脚本说明

- **quick-commit.ps1** - 快速提交和推送
- **pre-release-check.ps1** - 发布前检查（Git 状态、测试、构建、依赖）
- **generate-changelog.ps1** - 从 Git 历史生成 CHANGELOG.md
- **publish.ps1** - 完整发布流程（测试、版本更新、Git、NPM）
- **publish-pypi.ps1** - 构建并发布 Python 包到 PyPI
- **publish-npm.ps1** - 发布到 NPM（旧脚本）
- **commit-modeltoolbox.ps1** - 提交脚本（旧脚本）
