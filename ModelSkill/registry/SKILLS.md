# Skills

- `build-graph` - Build or update the code review knowledge graph. Run this first to initialize, or let hooks keep it updated automatically. (skills/build-graph/SKILL.md)
- `debug-issue` - Systematically debug issues using graph-powered code navigation (skills/debug-issue/SKILL.md)
- `explore-codebase` - Navigate and understand codebase structure using the knowledge graph (skills/explore-codebase/SKILL.md)
- `refactor-safely` - Plan and execute safe refactoring using dependency analysis (skills/refactor-safely/SKILL.md)
- `review-changes` - Perform a structured code review using change detection and impact (skills/review-changes/SKILL.md)
- `review-delta` - Review only changes since last commit using impact analysis. Token-efficient delta review with automatic blast-radius detection. (skills/review-delta/SKILL.md)
- `review-pr` - Review a PR or branch diff using the knowledge graph for full structural context. Outputs a structured review with blast-radius analysis. (skills/review-pr/SKILL.md)
